## Important notes on the XDM schema

- `xdm.email.recipients` has type `EmailAddress` but despite not being labelled Array, you MUST use `arraycreate()` when assigning values to it.
- `xdm.source.process.parent_process.*` fields do NOT exist. They look plausible but are not in the schema. Never use them.
- Fields with `XDM_CONST` types MUST be assigned `XDM_CONST` values, never quoted strings.
